# POSシステム（じゃがバター屋）

文化祭の模擬店運営で使用するために制作した、WebベースのリアルタイムPOSシステムです。

注文入力、厨房画面へのリアルタイム共有、注文ステータス管理、レシート印刷、売上データ保存を一体化しています。

## 概要

このシステムは、文化祭のじゃがバター屋で実際に使用することを想定して開発しました。

紙の注文管理では、注文漏れ、厨房への伝達ミス、会計後の集計作業が発生しやすいため、注文受付から厨房共有、ステータス管理、売上記録までをブラウザ上で行えるようにしています。

## 主な機能

- 注文入力（数量・トッピング・クーポン有無）
- Socket.IOによる厨房画面へのリアルタイム同期
- 注文ステータス管理（未調理 / 調理中 / お渡し中 / 完了 / キャンセル）
- SQLiteによる注文データの保存
- レシート印刷機能
- 管理画面での注文一覧・売上集計
- LINE Messaging APIを利用した通知機能

## 技術スタック

- Node.js
- Express
- Socket.IO
- SQLite
- HTML / CSS / JavaScript
- LINE Messaging API

## セットアップ

依存パッケージをインストールします。

```bash
npm install
```

`.env.example` を参考に `.env` を作成し、必要な環境変数を設定してください。

```env
LINE_CHANNEL_ID=
LINE_CHANNEL_SECRET=
LINE_ACCESS_TOKEN=
PORT=8443
```

## 起動方法

以下のコマンドでサーバーを起動します。

```bash
npm start
```

`npm start` が設定されていない場合は、以下のコマンドで起動できます。

```bash
node server.js
```

起動後、ブラウザで以下のURLにアクセスします。

```text
http://localhost:8443
```

## 開発で工夫した点

- 注文が入ると厨房画面へ即時反映されるようにし、口頭伝達や紙管理によるミスを減らしました。
- タッチ操作を想定し、文化祭当日の忙しい環境でも操作しやすいUIを意識しました。
- SQLiteに注文データを保存し、注文履歴や売上集計を後から確認できるようにしました。
- 注文ステータスを段階的に管理できるようにし、厨房側の作業状況を把握しやすくしました。
- LINE通知やレシート印刷など、実際の運用で必要になる機能も含めて実装しました。

## 注意事項

このプロジェクトは文化祭での利用を想定して制作したものです。

LINE通知やレシート印刷など一部の機能は、実行環境や外部サービスの設定に依存します。

公開用リポジトリには、`.env` や注文データベースなどの実データは含めていません。
